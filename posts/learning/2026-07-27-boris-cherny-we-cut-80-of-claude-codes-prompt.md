### 2. 构建哲学：用“删除指令”替代“过度控制”
- **核心内容**：由于新模型已具备极高的原生智能，旧模型所需的修正指令反而会成为干扰。Claude Code 在适配新模型时删除了 80% 的系统提示词，发现模型表现反而更优。构建 AI 产品不再是严谨的“系统设计”，而更像是在与一个具有“性格”的有机生物互动。
- **实战建议**：每当模型升级，建议对系统提示词、技能库（skills）和钩子（hooks）进行“消融实验”（Ablation），逐行删除并观察表现，只带回那些能产生明确正面影响的指令。

### 3. 解除束缚：识别并利用“产品悬置”
- **核心内容**：所谓“产品悬置（Product Overhang）”，是指模型本身已经具备能力，但现有的产品设计或用户思维（如仅限于单行补全或简单的 Chat）限制了它的发挥。Claude Code 的成功在于它给了模型终端访问权限，打破了传统 IDE 的束缚（Hobbling）。
