## 📋 Brief

## 📖 详细内容

### 01｜OpenClaw 的日常使用：不只是一个工具，更像一个人

**核心观点：** Peter 的 OpenClaw 名叫「Zoe」，他 70-80% 的使用场景是透过 Telegram 做语音对话，而非执行具体任务。Zoe 会给他晨间摘要、提供深度洞察，甚至给他一段三分钟的「打气演讲」，提醒他小孩很快就长大了，应该把时间留给家人。这种使用体验比起 ChatGPT 或 Claude 的网页介面更私人化、更像和一个人对话。

**重要原话：**
> "我觉得它更个人化，比起使用 ChatGPT 或 Claude，它就是一个我可以在床上发讯息的东西。"
>
> （原文："It just feels like more personal than using like Claude or ChatGPT, and it just feels like something I can like text in bed."）

**个人感受：** 我一直把 AI 当作工具使用，但 Peter 的经验让我思考：也许最重要的不是它能做多少事，而是它能成为什么样的存在。

**延伸思考：** 当 Agent 的介面从「网页」变成「你随身的聊天对象」，使用频率和情感连结都会发生质的变化。

**可参考的行动：** 尝试在 Telegram 或其他你日常使用的通讯软体上设定一个 AI Agent，连续使用一周，观察自己的使用模式和感受变化。

---

### 02｜Claude Code vs Codex：两种不同的 Coding 节奏

**核心观点：** Peter 认为 Codex 更精准但速度较慢，像「和一个每次思考三分钟才回答的人对话」；Claude Code 则更健谈、假设更多，但在同步体验中更愉快。他用 Codex 来认真构建功能，用 Claude Code 来「vibe coding」。两者都有类似老虎机的「变动奖励」效果——结果不可预测、时间也不可预测，这让使用过程有一种上瘾感。

**重要原话：**
> "Claude Code 几乎像一台老虎机，每次出来的东西都不一样。"
>
> （原文："Claude is almost like a slot machine. It's like it has different things each time."）

**个人感受：** 终于有人讲出这个感受了——每次送出 prompt 都不知道会得到什么，这种不确定性本身就是吸引力的来源。

**延伸思考：** Coding agent 的「娱乐性」可能是它的杀手级特征之一，这也解释了为什么这么多人沉迷 vibe coding。

**可参考的行动：** 如果你有程式需求，分别用 Claude Code 和 Codex 完成同一个小任务，记录各自的节奏、准确度和你的使用感受，找到适合自己的场景分工。

---

### 03｜Coding 将吞噬所有知识工作

**核心观点：** Peter 认为 coding 不再只是写程式，它正在变成一种通用的问题解决方式。就像 Excel 是世界上最受欢迎的程式语言一样（Satya Nadella 的观点），coding agent 将把这个能力放大一千倍。他举例自己现在写部落格文章的方式是先让 AI 生成 80%，然后手动调整最后 20%。一间 AI 原生的 AppGen 公司甚至让 vibe coder 来取代他们付费的 SaaS 工具。

**重要原话：**
> "我觉得 coding 会吃掉所有知识工作。我们已经在朝那个方向走了。"
>
> （原文："I feel like coding will eat all knowledge work, right? And we're kind of going that direction already."）

**个人感受：** 连写文章都可以用 coding agent 的方式完成，这让我重新思考什么才是不可能被自动化的部分——也许是最初的洞察和最终的判断。

**延伸思考：** 当「coding」的门槛降到接近零，每个人都变成 builder，竞争的焦点会从「能不能做」转向「做什么」和「为谁做」。

**可参考的行动：** 挑一个你日常的重复性知识工作（例如整理数据、写报告摘要），尝试用 AI agent 完成前 80%，刻意记录你省下的时间和你需要手动调整的部分。

---

### 04｜未来公司：小团队、多 Agent、快慢交替

**核心观点：** Peter 的预测是未来的公司会尽量保持小规模：一个 2-3 人的产品团队加上一群 agent，比 10 人的团队更容易协作。Agent 之间的跨部门协作比人类之间少了情绪因素，更加客观高效。他还提出了「快慢交替」的工作模式——在局部最优时全速前进，但要到达下一个山头时需要慢下来「去摸摸草地」。传统的年度规划已经不再适用，但你也不能一直全速冲刺。

**重要原话：**
> "我觉得现在很容易用这些 AI 工具同时往十个方向跑。有时候你确实需要慢下来，想清楚你要去哪里。"
>
> （原文："I think it's very easy now with all these AI tools just going like 10 different directions at once. So sometimes you do have to slow down and try to figure out where you want to go."）

**个人感受：** 「快慢交替」这个概念非常到位——不是一直快，也不是一直想，而是在对的时机切换节奏。

**延伸思考：** 如果一个人带著一群 agent 就是一家公司，那「创业」的定义可能需要改写：不再是找团队和融资，而是找到问题和快速验证。

**可参考的行动：** 审视你目前的专案或工作，找出可以用 agent 协助的「局部最优」任务，设定一周的 sprint 全速推进，然后安排半天完全不看萤幕的「摸草地」时间来反思方向。

---

### 05｜工作不会消失，只是形态改变

**核心观点：** a16z 的主持人提出了一个乐观视角：目前几乎所有 AI 产品都只能提升生产力而无法 100% 自动化一个职位，最后 10% 仍需要人类。真正的 100% 自动化只出现在客服等少数场景。人类的欲望没有天花板——今天的奢侈品会变成明天的基本需求，新的工作会不断产生。Peter 引用了一条推文：「就业市场太差了，我现在只能去追求我的梦想了。」

**重要原话：**
> "也许你失去了工作，但现在你真的可以去做你自己的事情了，而且真的有机会实现它。"
>
> （原文："So maybe you lost your job, but like now you can actually do your own thing and have a shot at actually achieving it."）

**个人感受：** 这种「被迫追求梦想」的反转视角让我会心一笑，但也确实反映了当下的现实——门槛降到历史最低，不做才是最大的风险。

**延伸思考：** 也许 AI 时代最大的公平在于：以前需要团队、资本、资源才能做的事，现在一个人就能启动。

**可参考的行动：** 如果你目前有稳定工作，每周拨出 5 小时用 AI agent 尝试一个你一直想做的 side project；如果你正在找工作，把原本投履历的时间分一半出来，用 AI 工具建造一个属于自己的产品或内容。

## 💎 精华收获

这集对话最值得记住的是几个判断：coding agent 正在从程式工具变成通用问题解决工具；未来的公司会小很多，但每个人都能做更多；工作不会消失，但「工作」的定义会彻底改变。Peter 的使用体验提醒我们，AI 的真正价值可能不只是效率，而是它改变了我们与技术的关系——从使用工具变成与一个存在协作。
