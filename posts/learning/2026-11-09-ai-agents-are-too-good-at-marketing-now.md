## 📖 详细内容

### 01｜广告是创业初期最高杠杆的动作

**核心观点：** Cody 认为广告是获取初期增长和验证商业想法最有效的手段。他形容这是他会教给自己 17 岁、创业却没客户的儿子的一小时课程。一旦你按这套 AI 流程做过一次，就再也回不去了，因为旧方式会显得像原始人的做法。

**重要原话：**
> “广告是获取初期增长、验证想法最高杠杆的事情之一。”
>
> （原文："Ads are one of the most high leverage things that you can do to get initial traction and also to validate an idea."）

**个人感受：** 我以前总觉得广告是大公司烧钱的游戏，小团队玩不起。但听完这个思路我意识到，问题从来不是广告本身贵，而是制作广告的人工成本高——现在那部分正在消失。

**延伸思考：** 如果制作 100 条广告变体的成本趋近于零，那创业验证的速度会彻底改变。你的瓶颈不再是「能不能做出素材」，而是「有没有好想法值得验证」。

**可参考的行动：** 今晚花 20 分钟写下你的目标客户的 3 个痛点和 3 个期望结果，这是后面所有广告生成的基础素材。

---

### 02｜所有营销都变成了代码

**核心观点：** 过去做一条广告需要平面设计师、文案、UGC 创作者、视频剪辑师、动效设计师这一整条人力链。现在这些工作全部变成了「软件 + tokens」，由 Agent 来执行。Cody 自己都没想到长视频剪辑这一年就做到了——一个叫 Mirage Tesseract 的工具可以一次性剪辑一个半小时的播客。

**重要原话：**
> “所有营销现在都只是代码，就是软件和 tokens。”
>
> （原文："All marketing is now just code. It's just software and tokens."）

**个人感受：** 听到长视频剪辑都能一键完成，我心里五味杂陈。一方面觉得这效率太爽了，另一方面想到认识的那几个剪辑师朋友，说实话有点替他们紧张。

**延伸思考：** 当「执行」环节的成本归零，人的价值会集中到「判断」环节——决定做什么广告、怎么定位、哪些方向值得投入。 taste 变成了核心竞争力。

**可参考的行动：** 挑一个你每周重复做 3 次以上的营销任务（比如写社媒文案），试着把流程写成一页步骤文档，为将来交给 Agent 做准备。

---

### 03｜你的新角色：搭一个「培养皿」

**核心观点：** Agent 不能凭空干活，你得给它搭建能正常工作的环境。Cody 的比喻是「培养皿」——你需要提供三样东西：业务数据的访问权限、工具（各种 API 调用）、以及广告平台和 CMS 的发布权限。你的工作不是亲手做营销，而是做指挥家。

**重要原话：**
> “让开，别挡 Agent 的路。你的工作是当指挥家。”
>
> （原文："Get out of the way of the agents. You are actually in the way. Your job is to be a conductor."）

**个人感受：** 「培养皿」这个比喻我一下就记住了。大多数人用 AI 不好用，不是模型不行，是环境没搭好——就像把鱼捞到桌子上还怪它不会游泳。

**延伸思考：** 这其实是一种新的技能分层：会「使用」AI 的人和会「给 AI 建基础设施」的人，产出差距会越拉越大。

**可参考的行动：** 列出你的 Agent 干活需要的三类资源清单：数据源、工具 API、发布渠道，看看缺哪几项。

---

### 04｜数据问题的标准答案：Airbyte + ClickHouse

**核心观点：** 直接让 Agent 去查各平台 API 会遇到限流、数据量太大导致幻觉、Agent 自己乱建本地数据库等问题。正确做法是用 Airbyte 做数据管道，把 Facebook 广告、Google Analytics、HubSpot 等所有数据源持续同步进 ClickHouse 数据仓库，然后让 Agent 随便查仓库。这样还能打通全链路——从广告曝光一直追溯到支付数据，看出哪类广告带来的是生命周期价值更高的客户。

**重要原话：**
> “你可以随便往这个数据仓库扔查询，随便轰炸都行。”
>
> （原文："You can nuke this data warehouse with queries."）

**个人感受：** 这段是我收获最大的。以前我也试过让 Agent 直接连 API，结果不是超时就是幻觉，原来是架构从一开始就错了。

**延伸思考：** 「打通数据孤岛」的真正价值是能回答「哪种广告带来更好的长期客户」这种问题，这比看单次转化率高一个维度。

**可参考的行动：** 注册 Airbyte 免费版，先接一个数据源（比如 Google Analytics）到 ClickHouse，跑通一条最小管道。

---

### 05｜平台接入的坑：为什么有人被封号

**核心观点：** 接 Facebook Ads、Google Ads 时要用 Marketing API 做单向写入——只用来上传素材、开关广告，所有数据读取都从自己的数据仓库走。否则 Agent 会一秒钟发上千个请求，违反平台服务条款，账号就没了。网上说「Agent 毁了我广告账户」的案例，本质都是这个原因。

**重要原话：**
> “你的 Agent 违反了 API 的服务条款，因为它一秒钟发几千个请求。”
>
> （原文："Your Grokbot violated the terms of service of the API because it was sending thousands of requests per second."）

**个人感受：** 主持人的比喻笑死我了——把 Agent 当成酒吧里喝到第八杯的黑大叔。真的一针见血，Agent 就是那种你不看着它就给你惹祸的伙伴。

**延伸思考：** 读写分离是个通用的 Agent 设计原则：把「读」放到自己控制的稳定系统，把「写」留给受控的官方接口，能避开大多数 API 灾难。

**可参考的行动：** 如果你在用 Agent 操作任何平台，立刻检查一下它有没有在做高频数据读取，有的话今天就改成「读本地仓库、写官方 API」的架构。

## 🧭 导师带你想：他最想让你带走的 3-5 课

### 第一课｜营销的执行成本已经归零

**他想让你先想一想：** 如果做一条广告和做一千条广告的成本几乎一样，你会先做哪个？

**他的答案（术）：** 把广告制作完全交给 Agent：给它品牌资料、客户痛点库、图像生成 API，让它批量产出品牌一致的静态广告和 AI UGC 视频。

**学以致用：** 本周用你手上的 Agent 工具 + 视频描述里的 skill 文件，生成 5 条针对不同痛点角度的静态广告，花一个下午就够了。

**怎么知道学会了：** 能展示 5 条风格统一但角度不同的广告，并且能说清每条对应客户的哪个痛点。

---

### 第二课｜你的工作是搭培养皿，不是亲手干活

**他想让你先想一想：** 你上一个小时做的营销工作里，有多少是「判断」，有多少只是「人肉搬运」？

**他的答案（术）：** 为 Agent 准备三样东西：业务数据（数据仓库）、工具（各平台 API 凭证）、发布渠道（广告平台和 CMS 的写入权限）。

**学以致用：** 花 30 分钟做一张「Agent 环境清单」表格，三列分别写数据源、工具、渠道，标注每项的状态（已有 / 待接入）。

**怎么知道学会了：** 当 Agent 卡住时，你能立刻判断是缺数据、缺工具还是缺权限，而不是换个提示词反复重试。

---

### 第三课｜数据别直连 API，走仓库

**他想让你先想一想：** 为什么你的 Agent 一查数据就幻觉或者超时？

**他的答案（术）：** 用 Airbyte 把所有数据源定时同步到 ClickHouse 数据仓库，Agent 只查仓库，不碰源头 API。

**学以致用：** 这周挑一个数据源（哪怕是简单的 Google Analytics）跑通 Airbyte 到 ClickHouse 的管道，预计两小时。

**怎么知道学会了：** Agent 能连续查询仓库数据 20 次以上，零限流、零幻觉数据错乱。

---

### 第四课｜假设你的 Agent 是个醉汉

**他想让你先想一想：** 如果 Agent 半夜自己往广告平台发一万个请求，你的账户还能保住吗？

**他的答案（术）：** 读写分离。数据读取只从自己的数据仓库走，官方 Marketing API 只用来做写入操作（上传素材、开关广告），并设置人工审核关卡。

**学以致用：** 今天检查一遍你所有的 Agent 自动化流程，找出所有直接调外部平台 API 的地方，标记出高风险的读取操作。

**怎么知道学会了：** 你的所有自动化流程都能回答「这个操作违反平台条款吗」这个问题，且关键发布动作前有人工确认。

## 🌳 背后的道：他的思想「树干」

**树根｜他最底层的信念：** 过去营销贵，不是因为营销本身难，而是因为每个环节都要人来做。人的执行劳动正在被 Agent 大规模替代，而这件事发生的速度比所有人预期的都快。

**树干｜核心思考框架：「营销即软件」框架——因为 Agent 能完成过去需要设计师、剪辑师、文案的所有执行工作，所以营销的生产成本从人力变成了代码和 tokens，于是你的唯一任务就是搭建让 Agent 高效运转的基础设施（数据、工具、权限），然后让开路。」

**枝叶对照：**

| 他的观点（枝叶） | 是怎么从树干长出来的 |
|------------------|----------------------|
| 广告是验证想法的最高杠杆手段 | 执行成本归零后，做广告变得又快又便宜 |
| 用数据仓库而不是直连 API | Agent 干活需要稳定的数据环境，培养皿要搭好 |
| 读写分离防止封号 | Agent 是不受控的执行者，基础设施必须替它兜底 |
| 人退居「指挥家」角色 | 执行交给机器后，人的价值只剩协调和判断 |

**这棵树的边界：** 这套框架假设你已经有了产品、定位和明确的客户画像——它解决的是「执行」问题，不解决「做什么」的问题。如果产品本身不行，再高效的广告机器也只是更快地烧钱。另外，完全自动化生成的广告在品牌调性敏感的行业（奢侈品、B2B 高客单价）可能还需要大量人工打磨。

**带走一句心法：** 别再亲手做执行了——你的任务是造好培养皿，然后让开路。
