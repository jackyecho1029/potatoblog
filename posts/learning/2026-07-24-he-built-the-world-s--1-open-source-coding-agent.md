**重要原话：**
> "A lot of companies would start using open code because they didn't want to be locked into using a specific model or a specific harness."
>
> （原文：很多公司开始使用 Open Code，是因为他们不想被锁定在某个特定的模型或特定的工具框架里。）

**个人感受：** 这打破了我「开源=便宜=小型企业或个人用」的刻板印象。对于大公司来说，「选择权」本身就有巨大的价值。被绑定在一个供应商身上，在技术快速迭代的今天，风险太高了。

**延伸思考：** 这解释了为什么像 Open Code 这样开放、模组化的工具能同时吸引个人开发者和 Fortune 500 强企业。它们解决的是不同层面的问题：个人要低成本，企业要灵活性和控制权。

**可参考的行动：** 如果你在一家公司负责技术选型，可以考虑引入一层类似 Open Code 的抽象层。这能让你的团队在未来模型更新换代时，有更大的调整空间，而不必进行痛苦的系统迁移。
